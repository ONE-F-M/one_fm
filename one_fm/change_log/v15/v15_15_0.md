# Version v15.15.0 Release Notes

Sprint 20 (19th August - 25th August 2026)

## Features & Enhancements

### GRD - Preparation Batches & Sequencing

- **WI-002101**: a Preparation is named after its Category (PRE-ONB-, PRE-OFFB-, PRE-REN-), and rows may only carry the Category's own Actions
- **WI-002093**: the employee grid shows where each candidate has got to (sub-document and its status, forward-only), replacing the Total Amount column
- **WI-002092**: a multi-year renewal charges each of its years (civil ID excluded); the duration picker restored; the rate is fetched whatever duration its master row is filed under
- **WI-002095**: an overseas hire's Preparation opens its Medical Appointment and PCC Attestation; no Fingerprint Appointment is opened for any Action
- **WI-002104**: a second PCC record is opened when the candidate's nationality needs a translation
- **WI-002107**: Preparation Connections badge the medical and the attestation
- **WI-002096**: a step cannot complete before the one in front of it; "Go to" buttons cover every classification and pair on Preparation and employee

### GRD - Work Permit, PACI, Residency & Visa Request

- **WI-002108**: amendments counted on the permit (Amend action and Amendment No) instead of duplicating it; reapply resets the count
- **WI-002097**: "Pending By Supervisor" renamed to "Pending GR Manager"; the permit scan is no longer demanded on the way out; an amended permit must state its designation; Employee Name on the list view
- **WI-002136**: a fee-free civil ID can be completed (No Payment Required route); Save routes on the Category; a rejection requires its reason; the PRO must record the PACI Reference and PRO User before handing back
- **WI-002109**: PACI carries the Damj details, each block shown and required only with its checkbox, enforced server-side; unticking clears what the box claimed
- **WI-002100**: a permit's corrected expiry is carried down to the Residency and PACI; a Damj completed on the PACI writes the merged Civil ID back to the Employee
- **WI-002105**: Residency exception details shown only when claimed; unticking clears server-side; existing records swept by patch
- **WI-002069**: Visa Request visibility and read-only rules brought over from the BA site; three never-written mandatory rules dropped; the GRD operator holder field added
- **WI-002145**: Assign PRO refused without a chosen PRO User; the GRO side assigned from the "Assigning GR Operator" Process Task
- **WI-002110**: PCC Attestation shows only the fields its Type actually uses
- **WI-002098**: an overseas hire's Medical Insurance is held in Draft until the portal is paid

### PAM Licence Compliance

- **WI-002102**: PAM License configuration migrated from the BA site (Occupational Sector, PAM License Details, PAM Licenses; PAM File laid out to match)
- **WI-002091**: a licence's nationals and expatriates counted from the active employees on it, recounted on both sides of an edit
- **WI-002094**: Required and Excess Nationals derived from the sector's ratio, stated to the nearest half
- **WI-002099**: Expats Allowed derived from the ratio plus the sector allowance (six sectors seeded); violation is actual minus allowed
- **WI-002135**: compliance status read-only and derived from the violation; existing licences restated by patch

### Payroll

- **WI-002153**: Operations Monthly Attendance Sheet renamed to Monthly Payroll Attendance Sheet and made company-wide - non-shift staff included, real Employee Status filter options, Day Off OT consolidates with Basic

### Transport - Schedule Canvas

- **WI-002160**: one trip group on one vehicle is one run, measured leg by leg against the seats; refusals name the runs holding the seats; trip names take the next free number; a cross-direction drop opens the Merge Trip modal
- **WI-002161**: a night shift's card shows the hours it actually covers; the return pickup moves to the real end time
- **WI-002162**: Transportation Manager and Supervisor can run Generate Shipments

### Content Requests

- **WI-002002**: the Action select carries no default; requester and approval chain fill in when the form opens; Document Register links show titles; input-material cataloguing and the dead status field removed

### Sprint Reports & Roadmap

- **WI-002112**: an orchestrator flag on Work Item; a human assignee alongside the flag is dropped, and an Epic refuses it
- **WI-002143**: sprint targets prorated by working days with public holidays included; the Business Analyst report gains the same time-off accounting, with working days, holidays and leave shown beside the figure
- **WI-002199**: the Roadmap backlog defaults to unsprinted Draft/Open non-Epics, with Backlog Status kept as a comma-separated status override

### Orchestrator & Process Engine

- **WI-002111**: a Work Item flagged orchestrator is routed into an agent that delegates, as a Call Activity in Software Development; the engine compiles and actually runs called process maps
- Every Call Activity gets its own visible Process Instance with honest timestamps; the tools a called process used are marked on its own page
- **WI-002090**: deploying a process model messages the Process Implementation instance waiting on it
- Deploy warns when an AI task has a system prompt but no user prompt

### A2A - Delegation Management

- **WI-002053**: every hand-over recorded as an Agent Delegation tying instance, task, worker and document together; one that stops at a limit escalates with a notification and a comment on the work item
- Refusal reasons and stopping limits reach the delegating model; the delegation deadline belongs to the orchestrator, not the worker
- **WI-002146**: a retry actually runs the worker again, with a fresh instance per attempt
- **WI-002056**: delegate shapes can require a capability, checked against the target's skill tags with the refusal naming who could do it; running delegations can be cancelled; editing a called map recompiles every caller
- **WI-002055**: the reconciler and timer sweeps get their own bpmn_clock queue, claimed only when the site declares it
- Delegations tab on the A2A screen with filters and a full-story modal; per-list page sizes; delegation limits editable from the agent's controls

### Clarifications

- **WI-002050**: an agent asks the story owner instead of guessing - every question is an AI Clarification record plus a comment on the document; questions surface on any doctype; a Clarifications tab on the A2A screen; the per-agent question cap settable from Processa

### Agent Identity & Permissions

- **WI-002054**: every agent acts as its own User with permissions on; every Work Item tool checks its permission itself; comments and reports are signed by the agent; roles editable from Processa behind an escalation guard; machine identities no longer narrow who can see agents

### Connector Agent

- **WI-002113**: a background agent that builds connectors from a delegated work order - fetches the API reference, drafts a deterministic manifest, validates before writing, tries one real call, and writes the connector disabled; Python handlers delivered as a pull request against the repository named in Processa Settings

### AI Platform

- **WI-001635**: BA Agent moved onto its own Processa map through the generic chat-turn path; the LangGraph runner retired; investigation bounded; honest fallback on a failed turn
- **WI-001862**: every Logix LLM call tracked as a real AI Agent Run, attributed to its own dedicated configuration
- **WI-002134**: one provider, one model, no rate card - credentials on AI Provider, pricing on the AI Model catalog; unpriced models priced
- **WI-001809**: AI Chat Settings folded into Processa Settings; General Chat's OpenAI/Gemini path repaired to resolve credentials through AI Provider
- **WI-002140**: the branded Guideline deck fills, and an Update revises the same Drive file
- **WI-002157**: any user or email field can be a notification recipient, owner and modified_by included
- **WI-002154**: generated lane diagrams dock edges by approach direction, so converging flows stop overlapping

## Bug Fixes

- The agent turn store is read past frappe's cache memo - a full analysis is no longer published as the single word "DONE"
- A saved transport run redraws on one day, ending phantom Overcapacity from day-wide bands
- A direction mismatch no longer unassigns a placed shipment card, which exposed it to deletion by Generate Shipments
- **WI-002211**: ONE AI workspace links to retired DocTypes repaired
- A connector tool that is not wired up returns an error instead of answering "ok"; an agent's clarification and delegation comments are signed by the agent
- An empty tool result no longer kills an Anthropic turn; a delegation the turn cannot collect is never started; the pause flag clears on every loop exit
- Stale pathfinder-log assignment rule patches removed and get_json_file error logging hardened, so neither can abort bench migrate
- Medical Appointment inserts cleanly again (a literal "User" default on its operator link failed validation on every insert)

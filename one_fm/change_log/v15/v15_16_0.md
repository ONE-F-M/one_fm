# Version v15.16.0 Release Notes

Sprint 21 (26th August - 1st September 2026)

## Features & Enhancements

### AI Agents - Conversation Memory

- **WI-001885**: old conversation turns are summarised instead of dropped (Chat Conversation Summary and the summarising window policy)
- **WI-001886**: compaction runs on a trigger and always in the background; the person waiting for a reply never waits for a summary
- **WI-001887**: conversation history is trimmed by token budget, not just by message count
- **WI-001888**: a daily retention sweep acts on idle conversations; a real race in the conversation store fixed
- **WI-001889**: a conversation-scoped scratchpad holds session state, consumed by six agents
- **WI-001891**: session lifecycle and compaction are visible from the Sessions screen, without Desk

### Processa - Software Development Process

- **WI-002119**: Notify Assignee sends once per task, not once per assignment; a User Task's Notify Assignee can name the Email Account it sends from

### Sprint Reports & Roadmap

- **WI-002199**: the Roadmap backlog defaults to unsprinted Draft/Open non-Epics, with Backlog Status kept as a comma-separated override
- **WI-002143**: Sprint Report targets are prorated by working days with public holidays included; the Business Analyst report gains the same time-off accounting

## Bug Fixes

- **WI-002270**: a BPMN gateway reads the context document as it is now, so the Visa process no longer halts at its gateway
- **WI-002211**: the ONE AI workspace links to the retired AI Chat Settings DocType are repaired
- one_fm #6827: `Warehouse.one_fm_project` custom field was missing on fresh installs
- one_fm #6797: the transportation schedule redraws a saved run on one day, not two
- one_bpmn #622: the sandbox runs as the agent that dispatched it, not always the Dev Agent
- one_bpmn #614: the AI task modal form loads, and models are no longer all reported disabled
- one_bpmn #615: Notify Assignee must name the mailbox it sends from
- one_bpmn #605: `get_agent_config` returns the agent's configured model
- one_bpmn #604: agent sandbox credential resolution fixed; the caller key moves to settings
- one_bpmn #606, #607: the sandbox callback URL is forced to https; a PR is opened even when tests fail, with the failure marked in the PR

## Chores

# Version v15.6.0 Release Notes

## Features & Enhancements
- Mobile API — new Employee Resignation backend with token-based authentication, attachment parsing, date-correction endpoint, and mobile utility layer (`mobile_utils.py`) for standardized parameter extraction
- Penalty & Investigation — full Legal module overhaul with damage tracking, validation rules, offence-level mapping, dashboard charts (Total Penalties, Penalty Applied This Year), penalty codes, and multi-stage workflow
- DMARC Settings — new DocType for email domain authentication configuration with settings integration and child table support
- Employee Resignation Withdrawal — new Pending Operations Manager assignment rule with process task integration and HTML email template
- Pathfinder module — Process Change Request refinements, BPMN integration button, status field updates, and Pathfinder Log cleanup (removed assignment rule and dashboard)
- Subcontract Staff Attendance — updated workflow and assignment rules (Operations Supervisor, Project Manager) with re-run patches
- Formal Hearing & Absence Case — ERP document seeding patch for stable migrations
- Purchase Receipt — added client-side JS override
- Attendance — client post off-count calculation for compliance checks

## Security
- Remove insecure authentication monkey-patch; implement secure dynamic API key generation
- Prevent unauthenticated employee enumeration by removing identifying details from guest API responses

- Set `is_private=1` on resignation letter attachments

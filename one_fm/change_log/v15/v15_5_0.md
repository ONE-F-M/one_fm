# Version v15.5.0 Release Notes

## Features & Enhancements
- Visa Management module - new Visa Request DocType with multi-stage approval workflow, creation from Job Offer, rejection remarks, and assignment rules (Recruiter, GR Operator, GRD Manager)
- Formal Hearing & Absence Case - new DocTypes with workflow, site transfer, leave extension request, time validation, 7/21-day absence notifications, and assignment rules (HR Officer, HR Manager, Operations Manager, General Manager)
- Subcontractor Contracts & Staff Attendance - new DocTypes with workflows, web form portal, date-wise attendance validation, working days recalculation, preview functionality, and assignment rules (Operations Supervisor, Operations Manager, Finance Manager, Subcontractor)
- Employee Resignation & Withdrawal overhaul - full rewrite with bulk withdrawal, replacement_required enforcement, Employee ID visualization in list view, PMR creation redirect, and assignment rules
- Project Manpower Request - new PMR Resignation Link, Linked Candidate, Fulfilled Employee, and Fulfillment Action DocTypes; ERF strictness enforcement via UI constraints
- Interview Console - 1-to-1 strict interview/feedback pairing, evaluation matrix dynamic loading, auto-scroll sidebar, sticky search bar, debounced saves with serialized writes
- Pathfinder module - Workspace creation, Process Roadmap and Process Change Request DocTypes, process classification enforcement, naming series, read-only mode when deployed
- Route Planner - manual route optimizer with manifest view
- Contracts - conditional approval workflow for amendments, item variant attributes, sales invoice generation using attendance amendment, item price creation
- Client Event & Interview Shortlist - updated workflows with 3-tier assignment rules
- Leave Application - workflow additions, reliever user ID custom field, leave outcome custom field, multiple assignment rules
- Timesheet - assignment rules for approver and employee
- HD Ticket - type custom field and Pathfinder integration
- Stock Entry - custom fields and stock balance override report
- Indemnity allocation - optimized scheduled job performance
- Accommodation Leave Movement DocType (new)
- Meeting Attendee DocType (new)

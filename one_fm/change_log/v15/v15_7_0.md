# Version v15.7.0 Release Notes

## Features & Enhancements

### one_fm
- Expense Claim — quick fixes for claim processing and validation (WI-000468)
- Biometric Data Sync — new feature to sync biometric device attendance data into the system
- Reliver Assignment Report — quick fixes for relief assignment display and filtering (WI-000313)
- Request for Materials (RFM) — Target Warehouse field is now mandatory to prevent incomplete material requests (WI-1690115)
- Route Plan — mobile view support for route planning pages
- Sales Invoice — item-wise grouping in print preview for cleaner sale summaries (WI-000462)

### one_bpmn
- BPMN Process Map Import — production-ready import support; import now works without requiring an active process map, enabling safe migration of process definitions across environments
- BPMN Guard — native Frappe `submit` and `cancel` actions are now blocked when a BPMN Process Instance is actively controlling a document; users are directed through the BPMN Actions menu to preserve workflow integrity
- Disable Process Model — new UI action to deactivate a deployed process map; includes a confirmation dialog with running instance count, server-side deactivation of linked Server Scripts, and clearing of serialized spec data
- BPMN Executable Attribute Guard — the `isExecutable` XML attribute is now enforced as a pre-deployment validation check, with clear UI warnings surfaced in the editor when the attribute is missing
- BPMN Editor — updated BpmnEditor frontend assets; added administrative migration scripts for data model transitions
- BPMN Instance Viewer — WAITING boundary events now render with a distinct blue pulse highlight, visually separating passive-listening events from READY/STARTED events

## Bug Fixes

### one_fm
- Route Plan — corrected review-point issues after mobile view PR merge
- Sales Invoice — applied Copilot Autofix security patch for a potential vulnerability in the item-wise grouping implementation

### one_bpmn
- BPMN Guard — fixed guard logic in `on_submit` and `on_cancel` hooks after a Frappe controller interface change broke the existing guard implementation
- Import — resolved error that prevented process map import when no active process map was present in the target environment
- BPMN Instance Viewer — excluded WAITING boundary events from sequence flow coloring; they were incorrectly rendering outgoing paths as traversed (green) even though the boundary had not fired
- `disable_process_model` — updated API docstring to accurately reflect the full return shape (`success`, `model`, `running_instances`) and the three-step disable sequence

## Chores
- one_bpmn: Updated `disable_process_model` docstring to document spec-clearing step and correct return shape after Copilot review feedback
- one_bpmn: Backported Executable attribute deployment guard (#134) to `version-15` branch via PR #135

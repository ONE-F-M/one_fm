# Version v15.8.0 Release Notes

## Features & Enhancements
- Candidate Country Process & Arrival — complete CCP and Arrival workflow with Overseas Medical Appointment (WAFID), Overseas Remedical, PCC Clearance, Visa Stamping DocTypes, auto visa result status update, CCP live ETA recalculation, optional CCP for local hires, and unit tests for arrival and deployment (#6087)
- Core Maintenance Modules — new Building, Space, Object, Object Template, Object Category, Maintenance Floor, Maintenance Frequency, and Object Maintenance Checklist DocTypes with child tables, validation logic, and floor/frequency management (WI-000691/692/693/694/695/696/697)
- Client Event & Operations Site — multiple site locations support in Operations Site with new Operations Site Location Items child table, Client Event check-in/checkout logic, and Event Staff controller (WI-000688)
- Hiring — auto-generate Candidate Country Process from Job Offer with try-except wrapping to prevent blocking workflow transitions (#6106)
- Route Planner — consolidated cross-plan daily manifest, drag-and-drop reordering of stops in shipment lanes, strict vehicle capacity validation, return shift card visibility in planner pool, vehicle reassignment deduplication fix, contact details on employee tags, responsive font sizing on timeline cards, and shipment order bug fixes (WI-000698/701/702/703/705/706/707)
- Rambo Replacement — rambo checkbox custom field on Employee DocType, rambo reliever custom field patch, and replacement feature for rambo staff (WI-000773/779/699/700)
- Client Interview Shortlist — email notification on interview shortlisting with updated workflow and controller logic (WI-000670)
- Bonus Request — print format feedback updates (WI-000690)
- Courier Integration — Transit Log courier API integration with OneFM system (WI-000709)
- Workspace Sorting — override Frappe's `get_workspace_sidebar_items()` to sort workspaces alphabetically by title instead of sequence_id (WI-000737)

- Job Offer — fix CCP auto-generate visibility and save bugs (#6119)
- Shift Request — penalty fix with improved shift request override logic (WI-000513)
- Face Recognition API — employee checkin override cleanup and v1/v2 API improvements (WI-000688)
- Route Planner — fix shipment order issues, restore standard Frappe page pattern, move back to ONE FM page structure (#6122)
- pyproject.toml — fix unescaped backslash in exclude pattern (#6128)
